SANTA CRUZ MOUNTAIN BIKING

Because most mountain bike trails in Santa Cruz are private, public ridership data is limited. This project gathers and visualizes trail popularity using Strava data while building practical experience with APIs and GIS tools.

Goals

  • Gather data on which Santa Cruz mountain bike trails are most popular.
  • Visualize trail ridership across the region.
  • Build practical knowledge of APIs, Python, and GIS tools.

Tools and Skills

  • Strava API through Python
  • ArcGIS Pro

Approach

API data collection

  1. Created a trail list manually through Strava segment search, using personal knowledge of the local trail network.
  2. Queried the Strava API for segment statistics for every trail in the list.
  3. Saved unique athlete counts, e-bike attempts, and pedal-bike attempts as separate datasets.
  4. Decoded each segment polyline into X/Y coordinates so the trail could be mapped.

Data cleaning and mapping

To import the results into ArcGIS, each coordinate CSV needed its first X/Y point to include the trail's attribute data. The gis_preprocess.py script automates this formatting and produces an ArcGIS-ready list of trail coordinates.

Some official segments covered only part of a trail, so those paths were extended manually before mapping.

Results

The resulting maps show the distribution of mountain bike ridership across the Santa Cruz trail network, with coverage for the full study area as well as focused views of UCSC and Nisene Marks.

Further Development

  • Collect data for more trails, especially the middle portion of UCSC and the climbing trails.
  • Visualize e-bike versus pedal-bike representation.
  • Analyze which days are busiest using the collected day-to-day ridership data.
