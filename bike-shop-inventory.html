BIKE SHOP INVENTORY MANAGEMENT

A Python application that automates bike-shop order entry through Clover's REST API, reducing manual work and improving inventory accuracy.

Goals

  • Automate order input through Clover's REST API.
  • Make the code easy to debug and update for future mechanics.
  • Make the order-entry workflow as easy to use as possible.

Context

The bike shop I work at uses Clover for inventory and sales management. Each year, physical inventory is compared with Clover's records, and discrepancies across more than 3,500 items can require a large amount of manual correction.

Orders previously entered by multiple employees through 7Spaces were inconsistent and time-consuming. This project improves the upstream process by standardizing order input and automating inventory updates.

Approach

1. Parse supplier files

Orders arrive from JBI and QBP in different formats. Order.py handles order parsing, while jbiqbp_scrape.py fills in missing product information. JBI data is scraped from its website, while QBP data is matched against a catalog TSV file.

Parsed products are loaded into OrderItem objects for consistent handling throughout the application.

2. Input items into Clover

The application sends items to Clover one at a time through the InventoryAdapter class in CloverAdapter.py. A log file records the actions taken so orders can be reviewed and troubleshooting can be targeted.

3. Support the mechanic workflow

gui.py is the central hub. It brings parsing, API input, logging, error handling, and user interaction together in a GUI designed for the shop's mechanics.

Project Structure

  • gui.py is the central application hub.
  • CloverAdapter.py connects the application to Clover's Inventory API through InventoryAdapter.
  • OrderItem.py defines the data abstraction for Clover items.
  • CloverOrderReaderAdapter.py extends the inventory adapter with order-reading functionality.
  • Order.py initializes and manages an order.
  • file_check.py handles logging features used by order parsing.
  • jbiqbp_scrape.py collects missing supplier information.
  • input_order.py is a deprecated non-GUI fallback for order input.

Future Development
