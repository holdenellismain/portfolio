EVENT SOFTWARE ANALYSIS

Using simulated event-conference software data, this project builds a stakeholder-facing report that visualizes sign-up patterns and turns the findings into concrete recommendations for improving registration rates.

Goals

  • Visualize basic metrics relating to sign-ups.
  • Recommend improvements that could raise sign-up rates.

Tools and Skills

  • SQL
  • Python
  • matplotlib
  • seaborn

Overview

The analysis uses simulated company data for an event and conference software platform. The work investigates sign-up volume by event type, attendee category, platform, month, and year while checking for operational and data quality issues before turning the results into recommendations.

Results

Event attendance, signed-up user attendance, and events all declined from 2023 to 2024. If that trend continues, the company will need to make major changes.

The company should collect more granular platform data for attendees and users. Current categories of mobile, web, and NA are too limited for reliable action.

Speakers had the lowest sign-up rate among attendee categories, a major missed opportunity because speakers create high-value networking connections for attendees.

In-person events had the strongest sign-up rate, while hybrid events performed slightly better than virtual events. Across event types, sign-up rates ranged from 64% to 82%, suggesting that the team should investigate high- and low-performing events for qualitative similarities.

Admins were most likely to sign up, followed closely by normal attendees, with speakers far behind. This indicates a meaningful gap in networking-related engagement.

Some recommendations were especially clear from the evidence. Mobile was the best-performing platform for event sign-ups, the web channel was under-used, and the unknown platform category was concerning. The report also recommends collecting more detailed device and operating system information, especially for mobile and web users.

Method

Data cleaning and table checks

  1. Check events for duplicate records, unusual date ranges, and invalid event types.
  2. Check reviewers and attendees for null values, double attendance of the same event, invalid deletion flags, irregular categories, and unexpected attendee counts.
  3. Check the users table for null values, duplicate user records, and irregular email patterns.
  4. Confirm joins between tables remain consistent and useful.

Transform the data

  1. Remove deleted users and normalize repeated attendee records by prioritizing admin or speaker accounts where needed.
  2. Pivot user type and platform variables for the event-level analysis.
  3. Load the cleaned data into a pandas DataFrame and convert date variables for time-series analysis.

Visualize and summarize

  1. Create the reporting visualizations with Python, matplotlib, and seaborn.
  2. Summarize the results and recommend changes for stakeholders.
  3. Export the final report as a PDF deliverable.
