ENGLISH PREMIER LEAGUE MATCH PREDICTION

A machine learning project that predicts Premier League match results from public data, including pre-match betting odds as both a benchmark and a model predictor.

  • View GitHub Repo

Project Context

This was my final project for a Fall 2024 machine learning course. It builds on my home advantage project and tests whether publicly available match predictors can improve on simple benchmarks.

Skills and Tools

  • Machine learning in R through tidymodels
  • Web scraping
  • Object-oriented data processing in Python
  • Data cleaning with dplyr in R
  • Data visualization with ggplot in R

Approach

1. Collect data

Betting odds came from Football-Data.co.uk. Match results were scraped from FBref, and league tables were scraped from Football365.

2. Build match predictors

Data was loaded into Python and processed through an object-oriented structure in classes.py. Each match received predictor statistics calculated from previous matches, producing a partial dataset.

3. Create the final dataset

In R, joins combined the partial match data with attendance statistics, home-advantage statistics, and the previous fixture result. The result was the final dataset documented in the project codebook.

4. Prepare model inputs

The dataset was processed to remove outliers, impute missing values, dummy encode nominal predictors, and normalize numeric predictors.

5. Fit and test models

Models were fit on training folds and evaluated on a test set. The classification models were multinomial elastic net, boosted trees, and random forest. A linear regression model instead predicted goal differential before converting that prediction into a match result.

Conclusions

Model accuracy

Home teams win 45% of Premier League matches, so always predicting a home win provides a simple baseline. Betting odds provided a stronger benchmark: selecting the outcome with the best odds over the last ten years produced 55.8% accuracy.

Elastic net multinomial0.55
Boosted tree0.55
Random forest0.56

The goal-differential approach required choosing a margin for draw predictions. I tested margins from zero to three goals using the training data.

The optimal strategy was to never predict draws, producing 55% training accuracy. On the test set, the random forest reached 56% accuracy and linear regression reached 55.6%. It remains inconclusive whether the random forest's small advantage would create a profitable long-term betting strategy because bookmaker accuracy varies by season and transaction costs require a larger edge.

Model observations

The random forest, linear regression classifier, and bookmakers used similar strategies, almost never predicting draws.

The linear regression model gave substantial weight to match significance, while the random forest relied on it less heavily. The importance of significance is also visible in the home team's conditional win probability.

Future Development

  • Add non-Premier League matches, including Champions League, Europa League, and FA Cup fixtures, to improve form, rest, and travel predictors.
  • Account for injuries and the importance of absent players.
  • Add older data while weighting recent matches more heavily.
  • Improve the algorithm for determining match significance by considering other teams' results.
  • Use prediction confidence to explore more nuanced betting strategies instead of selecting one result for every match.
